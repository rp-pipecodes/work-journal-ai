# Note and Task have independent accessible Hotkeys

Note and Task have independently remappable global Hotkeys, defaulting for new users to `Ctrl+Shift+Cmd+J` and `Ctrl+Shift+Cmd+T`. The earlier `Ctrl+Opt+Cmd+J` default and its obvious Task companion collide with documented VoiceOver commands because Control-Option is VoiceOver's default modifier, so the defaults move as a pair while combinations already chosen by existing users remain untouched. An installation whose database predates Tasks but has no explicit Note Hotkey is migrated by persisting the old default before the fallback changes; only a genuinely fresh database receives the new pair. The two actions may never share a combination; a refused remap rolls back without disturbing either live registration, and each action retains its own Tray Menu fallback.
