# The Standup Post never replaces Yesterday's Digest

The Tray Menu keeps both: `Copy Yesterday's Digest`, which renders the journal mechanically and puts it on the clipboard with no key, no network and no waiting, and `Write Standup Post…`, which asks a model. The plain one is the floor, and it is not to be folded into the AI one however much the two menu items look like duplicates.

[0015](0015-task-management-does-not-depend-on-ai-or-a-network.md) already says AI cannot become load-bearing for Tasks. This extends the same rule to reading back, which is the half of the app that makes capturing worth doing at all. Deleting the plain path would make the journal's only payoff depend on a network, a billable credential and ten seconds — and would mean an app that stops rewarding capture the day an API key expires.

## Consequences

- **Two Tray Menu items that a stranger will read as redundant.** They are not: one is a lossless rendering of what is in the journal, the other is prose that may be wrong. `CONTEXT.md` defines them as different things on purpose.
- **A Standup Post is never the source of anything.** It is not stored, never becomes a Note, and a failure to write one leaves the journal exactly as it was.
- **The plain path is what gets tested against.** If the Digest and the Standup Post ever disagree about what happened yesterday, the Digest is right.
