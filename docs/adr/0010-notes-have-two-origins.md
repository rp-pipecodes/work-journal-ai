# Notes have two origins

A Note now comes into existence either by Capture — the user typing one — or by Import, which turns a meeting on the user's calendar into a Note without being asked. Note therefore stops meaning "text the user wrote", and Captured At stops meaning "when the record was stored": it is the instant the Note is *about*, so a meeting swept up at 18:40 still sorts into the morning it happened in rather than collapsing a whole day onto one timestamp. An Imported Note is otherwise an ordinary Note — its Body is the event title verbatim, it is always Unfiled, and it is editable, refilable and deletable like any other. Rejected: proposing meetings for confirmation before they become Notes (deletion already exists and is permanent, so refusing is cheaper than confirming, and a meeting missed by a filter is never noticed); a separate meeting record beside Note (a second unit destroys "the unit of everything — there is no smaller or larger record"); deriving Project from which calendar an event sits on (this user's calendars carry no project or client meaning, so there is nothing to derive).

## Consequences

Imported Notes never Nudge — a Nudge means "you wrote something on another day", which is a fact about the user, not about a sweep. Once created, a Note stops following the calendar: later renames, moves and cancellations are ignored, and the user's edits win. Deleting an Imported Note also refuses the meeting permanently, which forces the app to remember which events it has already handled *separately from the Notes*, since the Note itself is gone. The tray counts Captured Notes only, because a count inflated by meetings would reassure the user precisely on the days they typed nothing.
